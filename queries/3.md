I was wondering what's the best way to create a prompt with
system part and
a user part consisting of a dynamically constructed set of mix of text and image URLs.
For the latter, I did not find automatic conversion of image URLs to ImageURLPart in the code, so I presume either:
construct ImageURLPart instances manually and return a list of those & plaintext or
use Computed Fields with the {url:image} syntax ... unless that is only valid inside a prompt template decorator?
Something like this?

```python
@prompt_template()
def image_analysis_prompt(system_prompt: Messages.System, batch: List[ImageURLPart]) -> List[Messages.Type]:
    messages = [system_prompt]
    for image_url in batch:
        messages.append(ImageURLPart(url=image_url))
    return messages
```

OTOH, if all the parts are of Messages.Type, I can just skip the @prompt_template decorator and use this with @llm directly?
